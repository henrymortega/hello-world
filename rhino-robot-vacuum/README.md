# Modern robot vacuum (Rhino)

A contemporary disc-style robot vacuum for a home — matte white body, charcoal bumper, LIDAR turret, status LED, drive wheels, caster, side brush, and main roller.

## The Rhino file

**`robot_vacuum.3dm`** — open this in Rhino.

## Rebuild

Rhino 8 ScriptEditor → open `robot_vacuum.py` → Run.

## Specs

- Diameter ≈ **350 mm**
- Height ≈ **98 mm** (including LIDAR)
- Units: millimetres, Z-up, wheels on the floor plane

Edit sizes in `params.py`. Layers: `01_Body` … `07_Sensors`.
