# Stylized spyglass (Rhino)

Low-poly wooden telescope matching the gold eyepiece, chrome draw tube, faceted collar, tapered barrel, cyan lens, and top sight.

## The Rhino file

**`spyglass.3dm`** — open this in Rhino.

## Rebuild

Rhino 8 ScriptEditor → open `spyglass.py` → Run.

Parts live on layers `01_Gold` … `06_Sight`. Apply a wood texture to `04_Wood` if you want grain like the reference.

Default length is about **160 mm** along X (eyepiece at the origin). Edit `params.py` to resize.
